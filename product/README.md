## The 60-second pitch

An in-house SDK that puts guided walkthroughs directly inside host products' UIs. Users get contextual help without leaving the app. Curriculum authors ship training as versioned JSON with no engineering ticket. Product teams drop it in in a few hours. Same code across every host product, so we build once and reuse — avoiding $6–24k/year per product in SaaS licenses (Appcues, Pendo, Userpilot). Ships in ~3 weeks; break-even inside year one on support ticket deflection alone.

## The 60-second stakeholder script

> "We're building a shared training system that lives inside every host product. First user is the example app — new users get a walkthrough on their first visit, workflow tutorials they can trigger anytime, and hover-hints on confusing form fields. The training team owns the content directly; engineering only sets it up once per product. We're avoiding roughly $12–24k a year in SaaS licenses per product, deflecting support tickets, and lifting first-week activation. Break-even is inside year one on the example app alone; every additional product is upside."
