## Known limitations (deliberate, resolved in Sprint 17)

- OpenAPI `ContentBundle` schema is `type: object` — placeholder. Generated from Zod in Sprint 17 via `zod-to-openapi` (T-250).
- No SDK-side integration yet. Content still ships in the host's build for every production adopter through v0.5.
- `POST /users/:userId/forget` is a stub that echoes the receipt shape; wiring to a real cross-device store lands with the persistent-store selection in the v1.0 execution window.
- Reference `InMemoryContentStore` resets on restart. Not for production — adopters plug their own store.

## Rollback

- Tag: revert to `v0.5.0` (stable). No SDK-side dependency on the API this preview, so hosts are unaffected by revert.
- Reference server: stop the process. No state to unwind.
