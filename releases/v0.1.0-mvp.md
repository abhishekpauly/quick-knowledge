## Rollback plan

See `rollback-runbook.md`. Fast path is a revert of the AI Platform consumption PR (~10 min).

Automatic rollback triggers:
- Onboarding completion drops below 20% in the first hour.
- `tour_error` rate exceeds 5% of `tour_started`.
- Console error rate up 3x from baseline.
- Any P0 bug reported.

## Post-launch review (Day 28)

## Known limitations shipping in v0.1.0

- Content is bundled with the SDK; updates require a redeploy of the host product. Content-served-from-API is v0.5+.
- Checklist pill shows total count only, not completed count (reactive per-tour count in the expanded view). Full reactivity in v0.2.
- Vue support absent. Only React products can adopt.
- No cross-device sync — completed on desktop = re-seen on mobile. LocalStorage is per-browser.
- No segmentation — all users see all tours (prerequisite gating aside). Segmentation in v0.2+ if PMs ask.
